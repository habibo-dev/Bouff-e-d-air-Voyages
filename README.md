# Bouffée d'air Voyages

Premium responsive website for **Bouffée d'air Voyages — Béjaïa, Algérie**.

## Stack
- React 19
- Vite
- CSS responsive
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on Vercel
The repository root is already configured for Vite with `vercel.json`.

> Contact details and social links should be verified with the agency before production publication. The request form is currently a front-end demo and does not send data to a backend.
